# Book Agent 📚🤖

一个面向个人阅读成长的智能读书 Agent。

## Vision

让 AI 成为长期阅读伙伴：理解书籍、陪伴阅读、沉淀知识、连接思想。

## Features

### Book Understanding Agent
- 书籍解析
- 章节摘要
- 核心观点提取
- 概念关系分析

### Reading Companion Agent
- 基于书籍内容问答
- 苏格拉底式讨论
- 阅读计划辅助

### Knowledge Memory
- 阅读历史记忆
- 用户观点沉淀
- 跨书籍知识关联

### Knowledge Graph
- 人物、概念、理论关系
- 多书知识连接
- 思想地图生成

### Learning Report
自动生成：
- 阅读笔记
- 思维导图
- 学习总结
- 复习问题

## Architecture

```
book-agent
├── agent            # Agent orchestration
├── skills           # Agent skills
├── knowledge        # RAG and graph memory
├── memory           # User reading memory
├── tools            # External tools
├── api              # Service layer
└── docs             # Documentation
```
